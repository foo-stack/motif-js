# Icons

Two surfaces in one section. The `@usemotif/icons` package ships individual glyph components
ready to render. The `Icon` primitive in `usemotif` wraps any of them (or any SVG component)
with size, colour, and stroke controls.

<CodeBlock lang="tsx" code={`import { Icon } from 'usemotif';
import { Camera } from '@usemotif/icons';

<Icon as={Camera} size={24} color="$colors.text.default" />`} />

Icon is exported from `usemotif` (and from `@usemotif/react` directly for tree-shake-sensitive
builds). The glyph components are exported from `@usemotif/icons` and can be passed to any
SVG-accepting component, not just `Icon`.

## Glyph set

`@usemotif/icons` ships hundreds of stroke icons as React components. Each is a thin SVG with
the same default size (24×24) and `stroke="currentColor"`. Pass one to `<Icon as={...}>` to
render it with motif's size/colour controls, or render the component directly.

<CodeBlock lang="tsx" code={`import { Activity, AlertCircle, Camera, Heart, Search } from '@usemotif/icons';

<Activity />
<AlertCircle width={20} height={20} />
<Camera color="#2563EB" />`} />

The full set is browseable in the sidebar via the searchable gallery below. Names follow
PascalCase — `AArrowDown`, `Accessibility`, `AirVent`, `AlarmClock`, and so on. Each glyph is a
named export from the package root.

## Cross-platform

Both surfaces work on web and native. The glyph components render as SVG via
`@usemotif/react`'s `Svg` primitive, which routes to a real `<svg>` on web and to
`react-native-svg` on native. No extra setup beyond the dependency.
