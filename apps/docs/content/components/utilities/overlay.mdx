# Overlay

<Lede>
  Overlay is a full-viewport scrim. It composes Portal with a fixed-position Box, so the backdrop
  covers everything regardless of where the call site sits in the tree.
</Lede>

<ComponentDemoStrip demo="overlay" />

<ArticleMeta />

## What it is

A `Portal` wrapping a `position: fixed` Box that fills the viewport, tinted with a translucent
scrim and centring its children. Because it portals, no ancestor's `overflow` or `transform` can
clip it - the scrim genuinely covers the page.

Overlay draws the backdrop, reports a click on the scrim itself, and isolates what is behind it:
background content is marked `inert` and `aria-hidden`, and page scrolling is locked while the
overlay is open. Both behaviours are opt-out through `isolateBackground` and `lockScroll`.

It does not trap focus or handle Escape. Compose it with
[FocusScope](/components/a11y/focus-scope) for the full modal contract.

## Install

`Overlay` is exported from `usemotif`. No separate install.

<CodeBlock lang="tsx" code={`import { Overlay } from 'usemotif';`} />

## Accessibility

`onScrimClick` fires only for a click on the scrim, not on the content - so tap-outside-to-dismiss
does not trigger when the user clicks inside the dialog. Pair it with an Escape handler so the
overlay is dismissible by keyboard as well as pointer; `onScrimClick` alone leaves keyboard users
without a way out.

The scrim dims the background, and by default Overlay also takes it out of the tab order and the
accessibility tree, and stops the page behind from scrolling. What it does not do is trap focus
inside itself or wire Escape. The full modal contract, isolation plus trapped focus plus Escape,
comes from composing Overlay with FocusScope, which is what the headless `Dialog` does.

Pass `isolateBackground={false}` and `lockScroll={false}` for a non-modal surface that should
leave the page usable.

## Examples

A scrim with tap-outside dismissal:

<CodeBlock lang="tsx" code={`<Overlay onScrimClick={close}>
  <Box bg="$colors.surface.base" p="$6" borderRadius="$radii.lg">
    {dialogContent}
  </Box>
</Overlay>`} />

A complete modal - Overlay plus FocusScope:

<CodeBlock lang="tsx" code={`<Overlay onScrimClick={close}>
  <FocusScope onEscape={close}>
    <Box bg="$colors.surface.base" p="$6" borderRadius="$radii.lg">
      <Heading>Delete project</Heading>
      <Text>This cannot be undone.</Text>
      <HStack gap="$2">
        <Button intent="neutral" onPress={close}>Cancel</Button>
        <Button intent="danger" onPress={confirm}>Delete</Button>
      </HStack>
    </Box>
  </FocusScope>
</Overlay>`} />
