# AspectRatio

<Lede>
  AspectRatio is a Box that enforces a fixed width-to-height ratio on its child. Reach for it when
  the surface needs to keep its shape across breakpoints - image cards, video embeds, social
  previews.
</Lede>

<ComponentDemoStrip demo="aspect-ratio" />

<ArticleMeta />

## What it is

A `<Box>` with the CSS `aspect-ratio` property set. The child element fills the container; the
container's height comes from its width and the supplied ratio.

## Install

`AspectRatio` is exported from `usemotif`. No separate install.

<CodeBlock lang="tsx" code={`import { AspectRatio } from 'usemotif';`} />

## Examples

Sixteen-by-nine cover image:

<CodeBlock lang="tsx" code={`<AspectRatio ratio={16 / 9} borderRadius="$radii.md" overflow="hidden">
  <Image src={cover.src} alt="" w="100%" h="100%" objectFit="cover" />
</AspectRatio>`} />

Square avatar slot:

<CodeBlock lang="tsx" code={`<AspectRatio ratio={1} w={120}>
  <Avatar src={user.avatar} />
</AspectRatio>`} />

Video embed:

<CodeBlock lang="tsx" code={`<AspectRatio ratio={16 / 9}>
  <iframe
    src={videoUrl}
    width="100%"
    height="100%"
    allow="autoplay; encrypted-media"
  />
</AspectRatio>`} />
