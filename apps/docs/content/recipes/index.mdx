## Patterns

Build a feature or solve a styling problem against motif's runtime.

| Recipe | What you build |
| --- | --- |
| [Dark mode toggle](/recipes/dark-mode-toggle) | A three-way light/dark/system toggle on `useThemeSetting`, with no first-paint flash. |
| [Build a design system](/recipes/design-system-from-scratch) | A typed, themed design system - tokens, primitives, components packaged for consumers. |
| [Theming CMS content](/recipes/cms-theming) | A per-section theme for content loaded from a CMS - pre-registered or runtime themes. |
| [Animation](/recipes/animation-patterns) | Prop-change transitions, mount-in entrances, and unmount-out exits with motion props. |
| [Forms](/recipes/form-patterns) | Accessible forms with `Field`, `Label`, `Input`, `FieldHelp`, and `FieldError`. |
| [Sub-themes per route](/recipes/sub-themes-per-route) | A route or route group with its own `Theme` boundary or theme chain. |
| [Print styles](/recipes/print-styles) | A print stylesheet - paper tokens, hidden chrome, controlled page breaks. |
