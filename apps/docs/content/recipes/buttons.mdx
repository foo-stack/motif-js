# Buttons

<Lede>
  To build a button family, wrap `Pressable` with `styled()`, add an `intent` axis for colour, a
  `size` axis for padding and type, and a couple of compound rules for the cases where the two axes
  interact.
</Lede>

<ArticleMeta />

## A neutral button

`Pressable` carries the interactive contract — cursor, `aria-disabled`, click suppression. Wrap
it with `styled()` to add the visual baseline.

```tsx
import { styled, Pressable } from '@motif-js/react';

const Button = styled(Pressable, {
  base: {
    display: 'inline-flex',
    alignItems: 'center',
    justifyContent: 'center',
    gap: '$space.2',
    fontWeight: '$fontWeights.medium',
    borderRadius: '$radii.md',
    transition: { property: 'background-color', duration: '$durations.2' },
    bg: '$colors.surface.muted',
    color: '$colors.text.default',
    _hover: { bg: '$colors.surface.subtle' },
    _focus: { outlineStyle: 'solid', outlineWidth: 2, outlineColor: '$colors.action.primary.bg' },
    _disabled: { opacity: 0.5 },
  },
});
```

`<Button>` is now a typed React component. It accepts `onPress`, `disabled`, every `Box` prop, and
the standard HTML attributes — `<Button type="submit">` reaches the underlying element.

## Add intent

Tone changes the colour family. Add an `intent` axis with the four choices the design supports.

```tsx
const Button = styled(Pressable, {
  base: {
    /* …same base… */
  },
  variants: {
    intent: {
      neutral: {
        bg: '$colors.surface.muted',
        color: '$colors.text.default',
        _hover: { bg: '$colors.surface.subtle' },
      },
      primary: {
        bg: '$colors.action.primary.bg',
        color: '$colors.action.primary.fg',
        _hover: { bg: '$colors.action.primary.hover' },
      },
      danger: {
        bg: '$colors.action.danger.bg',
        color: '$colors.action.danger.fg',
        _hover: { bg: '$colors.action.danger.hover' },
      },
      success: {
        bg: '$colors.action.success.bg',
        color: '$colors.action.success.fg',
        _hover: { bg: '$colors.action.success.hover' },
      },
    },
  },
  defaultVariants: { intent: 'neutral' },
});
```

Strip the `bg`, `color`, and `_hover` from `base` once intents own them — they would just be
overridden by the variant on every render.

## Add size

Padding, font size, and gap scale together.

```tsx
variants: {
  intent: { /* …as above… */ },
  size: {
    sm: { paddingBlock: '$space.1', paddingInline: '$space.3', fontSize: '$fontSizes.sm', gap: '$space.1' },
    md: { paddingBlock: '$space.2', paddingInline: '$space.4', fontSize: '$fontSizes.md', gap: '$space.2' },
    lg: { paddingBlock: '$space.3', paddingInline: '$space.6', fontSize: '$fontSizes.lg', gap: '$space.3' },
  },
},
defaultVariants: { intent: 'neutral', size: 'md' },
```

`<Button intent="primary" size="lg">Save</Button>` now takes both axes; both are typed; both are
checked.

## Compound rules

A few combinations need to break the orthogonality. Two examples:

- A `primary` button at `lg` size deserves a heavier weight.
- A `ghost` variant (transparent surface, hovered to a tint) only makes sense with the neutral
  intent.

`compoundVariants` carries those rules.

```tsx
compoundVariants: [
  { intent: 'primary', size: 'lg', css: { fontWeight: '$fontWeights.semibold' } },
  { intent: 'danger', size: 'sm', css: { borderWidth: 1, borderColor: '$colors.action.danger.bg' } },
],
```

The compound bag merges in only when every matcher is satisfied. The neutral and small sizes stay
untouched.

## Icon-only variant

For an icon-only button, square the padding and remove the gap. Do it as a third axis so call
sites stay declarative.

```tsx
variants: {
  intent: { /* … */ },
  size: { /* … */ },
  shape: {
    square: {},
    round: { borderRadius: '$radii.full' },
    icon: { paddingInline: '$space.2', paddingBlock: '$space.2', gap: 0 },
  },
},
```

```tsx
<Button intent="primary" size="md" shape="icon" aria-label="Save">
  <SaveIcon />
</Button>
```

When `shape="icon"`, the visible label is gone; supply an `aria-label` so the button still has an
accessible name. The interactive contract from `Pressable` carries that attribute through to the
DOM.
