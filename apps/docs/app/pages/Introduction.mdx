## Why we wrote it

Most styling libraries pick a side. They're built for the web first and ported to native, or built for native and asked to behave on web. We didn't want to choose. Motif compiles a single style declaration to atomic CSS classes on the web and to platform-native style objects on iOS and Android. Tokens resolve at build time. Variants are statically analyzable. Themes swap without re-render storms.

It's a small library — a handful of kilobytes gzipped — that does one thing well: it lets you describe how something looks, in a language that travels.

## What it gives you

- A style-prop API on every primitive (`<Box p="$5" bg="$colors.surface.muted">`)
- A `styled()` factory for component-level reuse
- A two-layer token system (raw scales + semantic tokens) with composable sub-themes
- Container queries, media queries, and three responsive syntaxes
- A static compiler that extracts what it can; a runtime that always works

## A first style

```tsx
import { Box, Heading, Paragraph, ThemeProvider } from '@motif-js/react';
import { lightTheme } from '@motif-js/tokens';

export function Hello() {
  return (
    <ThemeProvider themes={[lightTheme]} active="light">
      <Box p="$5" bg="$colors.surface.raised">
        <Heading level={1}>Hello, motif</Heading>
        <Paragraph>The same component renders on web and on native.</Paragraph>
      </Box>
    </ThemeProvider>
  );
}
```

The keys you see — `$5`, `$colors.surface.raised` — are token references. They resolve from the active theme. Rename a token in one place and every component that references it updates.

<Callout kind="tip" title="Tokens are the lever you pull">
  Three months from now, your designer will hand you a "small color tweak". If your accent is a
  token, it's a one-line change. If it's hard-coded into seven components, it's an afternoon — and
  one of them will be missed.
</Callout>

## Themes are bundles of tokens

A theme is a named bundle of tokens. The reason to name it is so you can have several — light, dark, brand-A, brand-B — and switch between them without a single component change.

```tsx
import { createTheme } from '@motif-js/react';

export const paper = createTheme({
  name: 'paper',
  tokens: {
    colors: {
      surface: { base: '#FBF7F2', muted: '#F5EFE6' },
      text: { default: '#1C1917', muted: '#57534E' },
      accent: '#C2410C',
    },
    space: { 1: 4, 2: 8, 3: 12, 4: 16, 5: 20, 6: 24 },
  },
});
```

<Callout kind="warning" title="One name per theme">
  Theme names are how the cascade resolves overrides — keep them stable. Renaming a theme is a breaking change for every component that references it via `<Theme name="…">`.
</Callout>
