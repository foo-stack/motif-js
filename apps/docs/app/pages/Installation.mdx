## Install the package

Pick your package manager. Motif ships as plain ESM with TypeScript types, so any modern JS toolchain will pick it up.

```sh
npm install @motif-js/react
```

```sh
pnpm add @motif-js/react
```

```sh
yarn add @motif-js/react
```

```sh
bun add @motif-js/react
```

`@motif-js/react` is the canonical entry. It re-exports the right renderer for the platform you are bundling for — `react-web` on Vite, Next, Remix, and any other web bundler; `react-native` when Metro picks it up. You do not import the renderer packages directly.

## Mount the reset and a theme

Motif is style-only. It does not own routing, layout, or the global stylesheet — it composes with whatever you already use. The two things you do need at the root of your tree are a CSS reset and a theme.

```tsx
import { ThemeProvider } from '@motif-js/react';
import { MotifReset } from '@motif-js/reset';
import { lightTheme, darkTheme } from '@motif-js/tokens';

export function App({ children }) {
  return (
    <>
      <MotifReset />
      <ThemeProvider themes={[lightTheme, darkTheme]} active="light">
        {children}
      </ThemeProvider>
    </>
  );
}
```

`MotifReset` is a `<style>` injection — it works the same in SSR, SSG, and client-only renders. If you already have a reset you trust, skip the import; nothing else in Motif depends on it.

`ThemeProvider` registers every theme you pass and activates one of them. Switching themes amounts to changing the `active` prop — the CSS-variable cascade does the rest, no React re-renders required.

<Callout kind="tip" title="Bring your own themes">
  The default `lightTheme` and `darkTheme` from `@motif-js/tokens` are starting points. Real apps
  almost always want a `createTheme()` of their own — see [theming](/docs/theming) for the full
  story.
</Callout>

## Wire the compiler (optional, recommended)

In production, the static compiler extracts tokens, responsive props, and pseudo states into atomic CSS classes at build time. Everything still works without it — the runtime path is a complete fallback — but turning it on cuts both the bundle size and the first-render cost.

For Vite (Remix, React Router framework mode, plain Vite SPAs), add the plugin and a single `import` to your root file.

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import motifExtract from '@motif-js/compiler-swc';

export default defineConfig({
  plugins: [
    // ...your other plugins
    motifExtract.vite(),
  ],
});
```

```tsx
// app/root.tsx
import 'virtual:motif-extract.css';
```

The `virtual:motif-extract.css` import is what pulls the aggregated atomic styles into your bundle. Without it, the extracted CSS is generated but not loaded — your app falls back to the runtime path.
