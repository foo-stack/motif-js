## Start with Box

`Box` is the primitive every other styled component is built on. It accepts every Motif style prop, plus `as` to pick the underlying element.

```tsx
import { Box } from '@motif-js/react';

export function Card() {
  return (
    <Box
      p="$5"
      bg="$colors.surface.raised"
      borderWidth={1}
      borderStyle="solid"
      borderColor="$colors.border.muted"
      borderRadius="$radii.lg"
    >
      A small box with brand padding, a hairline border, and rounded corners.
    </Box>
  );
}
```

The `$` prefix is the signal that a value resolves against the active theme. `$5` reads from the spacing scale, `$colors.surface.raised` reads from the semantic color layer, `$radii.lg` reads from the radii scale. Plain values still work — `borderWidth={1}` is a number, not a token reference, and that is fine.

## Compose primitives

Motif ships layout primitives so you do not have to remember which CSS property does what.

```tsx
import { Box, HStack, VStack, Text } from '@motif-js/react';

export function Profile() {
  return (
    <HStack alignItems="center" gap="$3">
      <Box width={40} height={40} borderRadius="$radii.full" bg="$colors.accentSoft" />
      <VStack gap={2}>
        <Text fontWeight="$fontWeights.semibold">Lina Park</Text>
        <Text color="$colors.text.muted" fontSize="$fontSizes.sm">
          Designer
        </Text>
      </VStack>
    </HStack>
  );
}
```

`HStack` is a flex row, `VStack` is a flex column. Both forward every other Box prop so you can override anything they set. There is also `Stack` (with an explicit `direction` prop), `Center`, `Grid`, `Wrap`, `Spacer`, and `AspectRatio` — see the [Box API](/api/box) for the full list.

## Pseudo states without a stylesheet

Hover, focus, active, and disabled states live on the same element as their resting style. The compiler emits the matching `:hover`, `:focus-visible`, `:active`, or `:disabled` rules.

```tsx
import { Pressable } from '@motif-js/react';

export function GhostButton() {
  return (
    <Pressable
      px="$4"
      py="$2"
      borderRadius="$radii.md"
      bg="transparent"
      color="$colors.text.default"
      _hover={{ bg: '$colors.surface.muted' }}
      _focus={{ outline: '2px solid', outlineColor: '$colors.focusRing' }}
    >
      Cancel
    </Pressable>
  );
}
```

`Pressable` is `Box` plus an `onPress` handler that maps to `onClick` on web and to `react-native`'s `Pressable.onPress` on native. Same JSX, two platforms.

## Responsive in three forms

Any style prop accepts a responsive object, an array, or a plain value. Pick the form that reads best for the case at hand.

```tsx
<Box
  // Object form — keys are breakpoint names from the active theme.
  px={{ base: '$4', md: '$6', lg: '$8' }}
  // Array form — positional, mobile-first.
  fontSize={['$fontSizes.md', null, '$fontSizes.lg']}
  // Plain value — applies at every breakpoint.
  py="$5"
/>
```

The defaults are Tailwind-aligned: `sm` 640, `md` 768, `lg` 1024, `xl` 1280, `2xl` 1536. Override them per `<ThemeProvider>` if your design system disagrees — the breakpoint set lives in the theme.

<Callout kind="info" title="Container queries too">
  Object keys prefixed with `@` are container-query breakpoints — `{ '@card.md': '$6' }` reads as "at the `card`-named container's `md` width." See [responsive](/docs/responsive) for the full story when that page lands.
</Callout>

## Reach for `styled` for repeating patterns

When the same combination shows up in three places, lift it.

```tsx
import { styled } from '@motif-js/react';

export const Button = styled('button', {
  base: {
    px: '$4',
    py: '$2',
    borderRadius: '$radii.md',
    fontFamily: '$fonts.sans',
    fontWeight: '$fontWeights.medium',
  },
  variants: {
    intent: {
      primary: { bg: '$colors.action.primary.bg', color: '$colors.action.primary.fg' },
      ghost: { bg: 'transparent', color: '$colors.text.default' },
    },
    size: {
      sm: { fontSize: '$fontSizes.sm' },
      md: { fontSize: '$fontSizes.base' },
    },
  },
  defaultVariants: { intent: 'primary', size: 'md' },
});

// <Button intent="ghost" size="sm">Cancel</Button>
```

Variants are typed: TypeScript knows `intent` is one of `'primary'` or `'ghost'` and refuses anything else. The variant story has its own page at [variants](/docs/variants).
