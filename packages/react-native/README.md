# @motif-js/react-native

> React Native implementations of motif-js primitives.

Most users want [`motif-js`](https://www.npmjs.com/package/motif-js) instead — its `react-native` exports condition routes Metro to this package automatically, while web bundlers route to `@motif-js/react`. Install `@motif-js/react-native` directly only when you want the native renderer without the cross-platform aggregation (e.g., to avoid pulling in `@motif-js/react` as a transitive dependency on a strictly native project).

## Install

```sh
yarn add @motif-js/react-native
```
