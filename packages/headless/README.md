# @usemotif/headless

> Accessible headless behavior primitives for motif-js - Dialog, Tabs, Combobox, Tooltip, Disclosure, and more.

Behavior plus accessibility, no styles. Bring your own visuals, or compose with `@usemotif/react` primitives.

## Install

```sh
yarn add @usemotif/headless
```

## What's included

Dialog, AlertDialog, Tooltip, Popover, Menu, ContextMenu, HoverCard, Checkbox, Radio, RadioGroup, Switch, Accordion, Collapsible, Tabs, Combobox, MultiSelect, Search, Select, Toast, CommandPalette, Progress, RangeSlider, RatingInput, Slider, Drawer, Sheet, Calendar, DatePicker, TimeInput, ColorPicker, FileUpload, TreeView, Breadcrumb, NavigationMenu, Pagination, Stepper, Toolbar.

Each component ships with both web and React Native implementations.
