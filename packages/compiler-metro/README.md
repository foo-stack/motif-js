# @motif-js/compiler-metro

> Metro plugin for React Native — runs `@motif-js/compiler-babel` inside the Metro pipeline so compile-time style-prop extraction works under Expo and bare React Native.

## Install

```sh
yarn add -D @motif-js/compiler-metro
```
